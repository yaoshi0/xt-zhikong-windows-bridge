# XT智控 Windows 接收端

这是 XT智控 0.4.8 对应的 Windows 电脑接收端。设备与电脑在可互访的同一局域网时，可以发送数字小键盘、媒体控制、快捷键和快捷文本，并打开已配置的电脑应用。

## 下载与连接

下载仓库中的 [`xtapp_bridge.bat`](xtapp_bridge.bat)（点击文件页面的 **Download raw file**），放在电脑的固定文件夹。需要 Windows 和 Windows PowerShell 5.1；不需要安装 Node.js 或 Python。

1. 双击 `xtapp_bridge.bat`。首次启动会进入配置向导。
2. 选择与设备处于同一局域网的**具体电脑 IPv4 地址**，不推荐选择 `0.0.0.0`。端口默认 `23334`。
3. 按提示选择要快捷应用指向地址；找不到时可跳过或输入完整路径。配置保存在 BAT 同目录的 `yxt_config.json`。
4. 保持接收端窗口运行，在 XT智控的连接设置中填写电脑 IP 和端口，然后测试连接。若 Windows 防火墙提示，仅允许可信的专用网络访问。

以后直接双击同一个 BAT 启动。重新配置可在命令行运行 `xtapp_bridge.bat setup`，也可在启动界面选择重新设置。停止服务时在接收端窗口按 `Ctrl+C`。

## 安全须知

- 接收端使用**无鉴权、未加密的 HTTP**。能访问该 IP 和端口的设备可能发送按键、文本或启动应用。只在可信局域网中运行，切勿将端口映射到公网。绑定具体 IP 可缩小暴露范围，但不能代替鉴权。
- 快捷文本发送到电脑当前前台窗口。发送前检查焦点，尤其不要在错误或不可信的窗口输入敏感内容。文本输入会临时写入电脑剪贴板并模拟粘贴，随后尝试恢复先前的纯文本；原剪贴板为空或包含其他格式时不保证恢复。
- BAT 从自身的 Base64 数据块解出 PowerShell 脚本到临时目录，再通过 `ExecutionPolicy Bypass` 运行。只运行可信来源的文件，并自行审阅代码。
- 若连接失败，检查两端网络互访、电脑 IP、端口、防火墙和端口占用。管理员权限运行的目标窗口可能不接受普通权限程序模拟的输入。

## 源码

[`src/remote_bridge.ps1`](src/remote_bridge.ps1) 是从 BAT 的 `::B64BEGIN` / `::B64END` 数据块逐字节解出的可读源码。BAT 本身就是可直接下载运行的完整接收端；修改源码后不能只替换此 PS1，还需重新生成 BAT 的内嵌数据块。

此仓库仅包含电脑接收端，不包含 XTApp 设备端项目。
